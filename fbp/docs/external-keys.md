# 外部連携キー

フレームワーク標準の連携機能を使わず、アプリ独自でAPI連携を実装する際に必要な認証情報・設定値を環境ごとに保存するシステム設定のノート。標準の連携機能に専用設定がある場合は、その設定を使う。

- システム設定の「Vimeo」の右隣にある「外部連携キー」で管理する。操作権限はシステム設定と同じく管理者。開発権限だけでは操作できない。アプリの管理アクセスガードも適用する。
- `key`: 必須・重複不可・255バイトまで。半角英字で始まり、英数字とアンダースコアを使用。大文字・小文字を区別する。
- `title`: 必須・255バイトまでの表示名。プログラムからの取得には使わない。
- `value`: 新規登録時必須・8,192バイトまで。空欄で編集すると現在値を保持する。上限超過時は切り詰めずエラーにする。
- 値の前後の空白、改行、数値に見える文字列を保持するため、固定長DB内の `value` はBase64形式（最大10,924バイト）で保存する。これは暗号化ではない。値の読出しは必ず下記APIを使う。
- 登録データ・バックアップ・FFM操作ログはリリース対象外。各環境で個別に設定し、リリース先の既存値を保持する。旧形式のリリースファイルにこのデータが含まれていても、受入時に除外する。
- 一覧・編集・削除画面・検索結果には保存値を返さない。FFM操作ログの値はマスクし、このノートのログ用スナップショットは作らない。通常のデータバックアップは認証情報を含むものとして取り扱う。
- 汎用業務ノートとして登録せず、汎用CSV・Note CRUDへ自動公開しない。アプリ側で取得した値をブラウザー、テンプレート、ログへ出力しない。

```php
// 未登録なら null。
$token = $ctl->get_external_key('example_access_token');

// 必須設定。未登録・空の場合は、値を含まない例外を送出する。
$token = $ctl->require_external_key('example_access_token');
```

既存のフレームワーク連携設定の自動移行や、このノートへの自動フォールバックは行わない。
