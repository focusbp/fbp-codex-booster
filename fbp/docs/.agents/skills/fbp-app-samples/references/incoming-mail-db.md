# Incoming Mail DB

詳細と初期値は`assets/incoming-mail/incoming-mail.json`を正本にする。2ノートともStandard Screen・管理者用・独立メニュー。

| ノート | 内容 |
| --- | --- |
| `sample_mail_accounts` | 名称、有効／停止、接続情報、暗号化パスワード、受信状態、最終受信日時、エラー概要 |
| `sample_mail_messages` | アカウント参照、重複防止キー、署名付き受信ID、件名、差出人、プレーン本文、添付名、保存日時 |

アカウントの標準追加・編集は名称と有効状態だけ。接続設定は専用ボタンで変更する。内部項目`receive_*`・最終日時・エラー概要を標準画面POSTから直接更新させない。パスワード欄は暗号化後1024バイト、`receive_state`は65535バイトで共通APIの保存上限と揃える。

受信メールは一覧・検索だけで、追加・編集・削除・複製を提供しない。`account_id`は`table/sample_mail_accounts`参照で表示は`{$title}`。`message_key`と`receipt`は内部項目。本文の上限は65535バイト、件名3000バイト、添付名6000バイト。添付の実体は保存しない。

アカウントを削除すると受信状態と再試行先を失うため、サンプルでは削除を提供せず停止で管理する。定期実行の登録、既存データの投入、SMTPの変更は定義インストーラーの対象外。
