# 取得方式と移行範囲

| 利用できる資料 | 入口 | 注意 |
|---|---|---|
| WordPress WXRとuploads | prepare --wxr | 下書き・非公開・予約日時も扱える。テーマ、プラグインDB、問い合わせ履歴は別資料 |
| 公開REST API | collectの既定 | 認証なしで返る投稿・固定ページ・カテゴリ・画像。カスタム投稿は--wp-typeで指定 |
| サイトマップ・RSS | collectが補完 | URL一覧や記事の補完。全記事・管理項目を得られる保証はない |
| 公開HTMLのみ | collect --wordpress off | 内部リンクとCSS等から収集。本文候補はページ全体のsnapshotで、本文抽出と再構成が必要 |
| JavaScript描画 | collect --render-js | 描画後DOMと動的GET素材。認証・POST依存の機能は取得できない |

公開収集は元の管理データの完全復元ではない。下書き・会員情報・受注/決済・受信履歴・検索インデックス・プラグイン設定は、資料がなければ未取得。取得できた画面と再構築する機能を分けて説明する。

ページホストと素材ホストを分ける。CDNや外部フォントが欠けていれば許可範囲・別資料を確認し、全ホストを無制限に許可しない。robotsや認証で止まった場合は回避せずエクスポート等を相談する。API/サイトマップが存在しないだけならHTMLへフォールバックできる。

## レビュー項目

- 固定ページ、ブログ、カテゴリ、ページ送り、共通ヘッダー/フッター、ロゴ・favicon。
- srcset・遅延読込み・CSS背景、PDF、アイキャッチ、ギャラリー、短縮コード。
- フォームの項目・同意・宛先・重複送信・失敗時の保存/通知。元の外部フォームへPOSTするだけの移植にしない。
- コメント、検索、会員、決済、予約、地図/動画等の埋込みと外部連携。コメントやカスタムフィールドは標準の候補データへ自動変換しないため、必要なら原本から別途マッピングし、機能Skillへ分担する。
- 元の公開範囲・日時・言語、対象外ページ、旧URLと新FBP入口の対応。
- テーマ資産の利用権・依存ライブラリ。テーマPHPは実行しない。

HTMLのみならヘッダー・本文・フッターを分離して管理ノートへ適応する。必要なCSS/JSをアプリ資産として整理し、旧ホスト・画像等をFBPのURL/素材配信へ接続する。外部リンクやmailto/telを誤って内部ページへ変換しない。ツールがデザインを自動再現したと説明しない。

原本、capture、prepared、実行結果を分けて保全する。captureのobjectsは原本、migration.jsonはレビュー前の候補。整合性検査を通すために原本を書き換えず、変換・除外は新しい版と対応表へ記録する。

collectのcompleteは承認済み範囲のキューが終わった意味に限定される。除外ホスト・未取得・動的参照を確認し、サイト全体・非公開データ・全デザイン・移行完了の証明と扱わない。
