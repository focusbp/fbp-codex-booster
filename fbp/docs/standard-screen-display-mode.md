# 標準画面レスポンシブ切り替え

2026-09-19。設計に沿って実装・検証し、`a603e20` を本番リリース済み。app-daitomirakuは「1:パソコン」へ変更し、本番設定の再取得で確認した。

## 設定と動作

- システム画面の「WEB」パネル、既存の Viewport 設定の直前に「標準画面レスポンシブ」を追加する。選択肢は `0:レスポンシブ` / `1:パソコン`。
- アプリ全体で共有するシステム設定とし、ユーザー別・ノート別の設定にはしない。
- 保存キーは `standard_screen_responsive`、定義は `standard_screen_responsive,1,N`。値1だけをパソコン扱いとし、未設定・空・不正値は0に正規化する。初期セットアップの既定値も0。
- 0では現在の動作を維持する。表示領域700px以下で検索＋一覧・マニュアルソートのメイン一覧をカード化し、検索項目と日付範囲を縦並びにする。
- 1では上記のカード化・縦並び・モバイル用幅制限解除を無効にし、従来の表形式と管理画面の最小幅800pxを使う。狭い端末では必要に応じて横スクロールする。ノート側の横スクロール設定も従来どおり有効にする。
- 共通ヘッダーも同じ設定で切り替える。1ではタイトル・タグライン・ログインユーザー名を隠すモバイル用レイアウトを無効にする。共通ヘッダーのため、管理画面内の独自画面を開いた場合にもこの選択が適用される。
- カレンダー・単一レコード・子ノートのサイドパネル・独自画面の本文は今回の一覧切り替え対象外。公開ページ・ログイン画面も対象外。
- 管理側・公開側の既存Viewport設定は書き換えない。0の判定基準は端末種類ではなくCSS上の表示領域幅なので、管理側Viewportに固定幅が設定されていればその幅に従う。
- 保存後は既存の全画面再読込で反映する。他の開いた画面は再読込後に反映する運用とする。

## 実装方針

- `app/setting/fmt/setting.fmt`、設定クラス、WEBパネル、言語JSON、CLI初期セットアップへ項目を追加する。表示・保存・CLIで既定値と正規化を統一する。既存設定の形式更新では他項目を保持する。
- 管理画面の `app/base/Templates/index.tpl` のbodyへ、正規化した設定に応じた表示モードクラスを付ける。
- `css/appstyle.css` の標準一覧用700px以下のブロック全体と、`app/base/style.css` のモバイルヘッダーブロック全体をレスポンシブモードに限定する。既存の一覧識別クラスは対象画面判定に使う。
- 一覧CSSの後半には一覧識別クラスを条件にしないセレクターもあるため、`db_exe_responsive_list` の付け外しだけでは切り替えが不完全になる。表・セル・ボタン・幅・固定スクロールバーまで一括して条件を揃える。
- `app/db_exe/Templates/rows_manual_sort.tpl` のドラッグ用複製要素は、画面幅だけでなく実際の表示モードも判定する。狭い画面でもパソコンモードなら表の列幅を固定する。元の行へ幅を残さない修正は維持する。
- セレクト・日付選択等の共通入力部品の改善は維持し、今回の設定で共通部品全体を過去版へ戻さない。
- CSS条件は管理画面のbodyクラスを基準にし、Ajax検索・追加読込・メニュー遷移でも同じモードを維持する。
- システム設定データは通常のアプリリリースで転送されないため、フレームワーク配布だけでは既存クライアントを1へ変更しない。希望する環境で個別に選択する。

## 実装後の検証

- 未設定・0・1の表示、設定保存と再読込、既存設定データの保持、CLI初期値を確認する。
- 375/700/701/1280pxで両モードを比較し、パソコンモードは9月18日のレスポンシブ変更前のレイアウトと照合する。
- 通常一覧・検索・日付範囲・横スクロール有無・行ボタン・Ajax再描画・マニュアルソートを確認する。
- 並び替え後の幅変更、ヘッダーのメニュー・パスワード変更・ログアウト、編集ダイアログを確認する。
- カレンダー・単一レコード・サイドパネル・独自画面本文・公開画面への意図しない影響がないことを確認する。
- Standard Screen Skillに表示モードの仕様を反映済み。

## 検証結果

- 既存設定の形式更新・全既存項目の保持・両モードの保存は回帰テストで確認済み。
- ブラウザで設定画面からの選択・保存・再読込、通常一覧／マニュアルソートの375・700・701・1280px表示、検索・クリアによる再描画、横スクロール有無を確認した。375pxではレスポンシブの実幅375px・はみ出しなし、パソコンの実幅800px。
- 編集・パスワード変更ダイアログ、メニュー、ログアウト、両モードの実ドラッグ保存と並び替え後の幅変更を確認した。JavaScriptエラーなし。
- 検証用ノート・データを削除し、設定は検証前の状態へ復元済み。検証用ノートのStandard ScreenチェックはERRORなし、意図的に未設定のサイドパネル項目に関するWARNのみ。
